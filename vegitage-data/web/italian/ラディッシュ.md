# ラディッシュ

*Raphanus sativus* — 大地から素早く芽吹く、小さくも奥深い根菜の物語

ラディッシュ（*ravanello*）は、アブラナ科（Brassicaceae）に属する根菜です。ラテン語 *raphanus* はギリシア語の「容易に現れる・早く成長する」に由来し、播種から数週間で収穫できる性質を表しています。地中海のラディッシュは中央アジア・カフカス起源の系統に属し、前ローマ時代には欧州で栽培化が進んでいました。古代ローマでは大プリニウスが消化を助ける機能性食品として、コルメラが春作の栽培技術として記録し、ルネサンス期には **マッティオーリ** が結石を砕く薬草として体系化しました。

冬には黒皮の大型品種 **ラモラッチョ**（黒大根）が食卓を支え、くり抜いて蜂蜜を詰めた咳止めシロップなどの民間療法も伝わります。伝統的農産物（PAT）としては、ピエモンテの長ラディッシュ **タバッソ** や、サルデーニャの **ラバネッロ・ルンゴ・ディ・セストゥ** が知られます。

現代の生産は高度に産業化され、**ラツィオ州** のアグロ・ポンティーノ（干拓による砂質土壌）がイタリア生産の過半を担い、大規模な温室栽培から生産量の多くがドイツなどへ輸出されています。イタリアはラディッシュ種子の生産地としても重要な地位を占めています。

詳しくは各ガイドへ ── **歴史**（語源と起源・ローマの農書・ラモラッチョ・ラツィオの産業化）／**栽培**／**料理**。

# キュウリ

*Cucumis sativus L.* — ウリ科の夏野菜、古代ローマからの伝統

キュウリは、ウリ科キュウリ属の一年生植物で、未熟な果実を食用とします。真のキュウリ（*Cucumis sativus*）の起源はヒマラヤ南麓とされますが、イタリアには「キュウリとして食べるメロン」（*Cucumis melo*）という独自のカテゴリーも並存し、これがイタリアのキュウリ文化を特徴づけています。

古代ローマでは皇帝ティベリウスがキュウリを好み、雲母板で覆う移動式の温室栽培が発達しました。中世にはアラブ世界を経て新たな品種が伝わり、ラテン語の *cucumis* から現在の *cetriolo* へと呼称が移りました。ルネサンス期には詰め物料理やサラダとして洗練されていきます。

生物多様性の宝庫である **プーリア州** では、メロン系の **バラッティエーレ** や **カロセッロ** が栽培され、苦味がなく消化が良いことで知られます。真のキュウリでは **ポリニャーノの半長キュウリ** が代表的で、いずれもP.A.T.に登録されています。アブルッツォ州の長大な **トルトレッロ**（蛇メロン）とともに、これらの在来品種は乾燥・高温に強く、気候変動への適応策としても再評価されています。

詳しくは各ガイドへ ── **歴史**（古代ローマの温室・メロン系品種・在来種保全）／**栽培**／**料理**。

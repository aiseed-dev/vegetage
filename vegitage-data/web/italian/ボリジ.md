# ボリジ

*Borago officinalis L.* — ムラサキ科の「星の花」、リグーリアの宝

ボリジは、ムラサキ科（Boraginaceae）に属する一年草で、全草が粗い剛毛に覆われ、五芒星のような鮮青色の花を咲かせます。原産は地中海東部から西アジアで、イタリアではほぼ全州に自生または栽培されています。古代ギリシア・ローマではディオスコリデスや大プリニウスが精神を高揚させ憂鬱を払う薬草として記録し、中世には **サレルノ医学校** の『養生訓』で血液を浄める重要な薬草に位置づけられました。

食文化として最も深く根づくのが北西部の **リグーリア** です。春の野草ブーケ「**プレボッジョン**」の中心を担い、その詰め物パスタ「**パンソティ**」はクルミのソースとともにこの地の名物となっています。南部の **プーリア** でも歴史的に重用され、2020年に州の伝統的農産物（PAT）として登録されました。

現代では、種子油に豊富なγ-リノレン酸（GLA）が化粧品・サプリメントに利用される一方、葉や花に含まれるピロリジジンアルカロイドの肝毒性から、イタリアではサプリメントへの葉・花の使用が禁じられています。近年はジンなどクラフトスピリッツの素材としても再評価されています。

詳しくは各ガイドへ ── **歴史**（語源と象徴・サレルノ医学校・リグーリアの食文化）／**栽培**／**料理**。

# カッペリ

*Capparis spinosa L.* — 地中海岩場の乾燥適応植物

カッペリは、フウチョウソウ科（Capparaceae）の低木で、開花前の蕾を塩漬けや発酵で調味料とし、果実（ククンチ）も食用にします。乾燥・強風・痩せた土壌に適応し、岩の割れ目に根を張ります。イタリア語「Cappero」はアラビア語・ペルシア語の *al-qâbar* に遡り、北アフリカ・中東を起源として地中海北岸へ伝播した経路を示します。栽培化の過程で、棘のある野生種から棘のない変種（var. *inermis*）が選抜されました。

サルデーニャの遺跡では約1万年前の炭化種子が見つかり、先史時代からの利用が確認されています。古代ローマではプリニウスがイタリア産を高く評価し、アピキウスの料理書やルネサンス期のスカッピの宮廷料理でも重用されました。医薬品と食材の境界にある植物として、浄化・鎮痛などの効能が古くから信じられてきました。

主産地はシチリアの島嶼で、**パンテッレリア島** の「**Cappero di Pantelleria**」は1993年にイタリア初のカッペリのIGPを取得し、溶岩石の段々畑での手作業は「英雄的農業」と呼ばれます。**エオリエ諸島** は2020年に「**Cappero delle Isole Eolie**」としてDOP登録されました。乾燥に強く灌漑を要さないため、気候変動下で持続可能な作物としても再評価されています。

詳しくは各ガイドへ ── **歴史**（語源と伝播・古代の医食・IGPとDOP）／**栽培**／**料理**。

# タンポポ

*Taraxacum officinale* — キク科の救荒植物、春の野草料理の主役

タンポポは、キク科（Asteraceae）に属する多年草で、若葉や根、蕾までを食用とします。イタリア語では **タラッサコ（Tarassaco）** と呼ばれ、葉の切れ込みを獅子の牙に見立てた「デンテ・ディ・レオーネ」や利尿作用に由来する「ピッシャレット」など、150以上の地方名を持ちます。平原から標高1,700メートルの山地まで広く分布し、強靭な生命力から救荒作物として重んじられてきました。

古代の医学書では野生チコリと混同されがちでしたが、10〜11世紀のアラブ医学が利尿・肝臓浄化の効能を体系化し、16世紀のルネサンス期に利用が広がりました。冬にたまった毒素を春に排出する「タラッサコテラピア（デトックス）」の習慣もこの頃に定着します。

野生植物を食べる知恵「アリムルジア」の代表格として、南チロルの **ジゴリ・サラート** や、石灰質土壌で苦味の少ない **タラッサコ・ディ・コンコ**（ヴェネト州、PAT認定）などが知られます。根を焙煎した代用コーヒーやスローフード登録の **タンポポ蜂蜜** も特徴的で、近年はEUのRADIANTプロジェクトで「未利用作物」として再評価されています。

詳しくは各ガイドへ ── **歴史**（アラブ医学・ルネサンスの普及・アリムルジア・現代の再評価）／**栽培**／**料理**。

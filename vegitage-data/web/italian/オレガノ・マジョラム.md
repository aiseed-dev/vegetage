# オレガノ・マジョラム

*Origanum vulgare L.* — シソ科の芳香植物、地中海料理の基本

オレガノとマジョラムは、シソ科（Lamiaceae）オレガノ属（*Origanum*）に属する芳香植物で、香りを持つ葉が用いられます。イタリアには主に4種が分布し、北・中部に広がる **Origanum vulgare**、南部やシチリアで料理用に珍重される **Origanum heracleoticum**、栽培種のマジョラム（*Origanum majorana*）、シチリア東部の希少種 **Origanum onites** が知られます。名はギリシャ語の「山の喜び」に由来します。

古代ローマではプリニウスが薬草として、アピキウスが調味料として記録し、中世には修道院の薬草園で受け継がれました。利用には南北の対比が際立ちます。南イタリア（**カンパニア**・**カラブリア**・**シチリア**）では野生のオレガノを採取する文化が根づき、**ピッツァ・マリナーラ** など乾燥オレガノを使う料理に不可欠でした。一方、北西部の **リグーリア** では甘く繊細なマジョラム（方言で「ペルサ」）が好まれ、詰め物料理やペーストに用いられます。

現在はオレガノ単独でのDOP認定は稀ですが、シチリアの **Origano di Villarosa** やバジリカータの **Origano del Pollino** など、伝統的農産品（PAT）として地域ブランドが保護されています。世界的に食品偽装が多いハーブでもあり、産地保証や有機栽培への転換が進んでいます。

詳しくは各ガイドへ ── **歴史**（語源と神話・古代ローマ・南北の対比）／**栽培**／**料理**。

# 西洋梨

*Pyrus communis L.* — 古代ローマから栽培されてきた果樹

西洋梨（*Pyrus communis*）は、バラ科ナシ属に属する果樹で、その果実を食用とします。コーカサス地方を起源とし、ギリシャを経てイタリア半島へ伝わりました。古代ローマ人は接ぎ木技術で品種を固定・増殖させ、カトーの時代に数種だった品種は大プリニウスの時代に大きく増えました。中世には修道院が遺伝資源を守り、ルネサンス期には **アルドロヴァンディ** の植物学や、メディチ家の宮廷画家 **ビンビ** の静物画が多様な品種を記録しました。

イタリアは現在、EU最大の西洋梨生産国です。「梨の女王」と称される **アバテ・フェテル** は、フランス原産ながら戦後 **エミリア＝ロマーニャ州** のポー川流域に適応し、実質的に「イタリアの梨」となりました。品質認証には **エミリア・ロマーニャの梨**（IGP）や **マントヴァの梨**（IGP）があります。

一方で、**ヴォルピーナ**（キツネの梨）、果肉が赤く染まる **ココメリーナ**、ピエモンテの **マデルナッサ** など、煮込みや保存に適した在来品種も、スローフード運動のもとで「忘れ去られた果実」として再評価されています。近年はクサギカメムシの被害や気候変動が産業に打撃を与えています。

詳しくは各ガイドへ ── **歴史**（ローマの接ぎ木・修道院とルネサンスの記録・アバテ・フェテルの物語・在来品種の復興）／**栽培**／**料理**。

# ズッキーニ

*Cucurbita pepo L.* — ナポリとミラノが育てた「夏カボチャ」

ズッキーニは、ウリ科（Cucurbitaceae）に属するペポカボチャ（*Cucurbita pepo*）の未熟果を食用とする果菜です。原産は新大陸（メソアメリカ）で、16世紀にヨーロッパへもたらされました。イタリアには古くからアフリカ原産のユウガオ（*Lagenaria*）を若採りで食べる習慣があり、これが新大陸のカボチャを受け入れる素地となりました。

長果型のズッキーニは、南北の二つの系統として成立します。南イタリアでは **ナポリ** 周辺で **ココゼッレ（Cocozelle）** グループが早くから育成され、1811年以前の文献に現れます。今日世界標準となった均一な円筒形の濃緑色ズッキーニは、1850年頃に **ミラノ** 近郊で成立した **Zucchini** グループを直接の起源とします。「Zucchini」の名はトスカーナ地方で小さな乾燥ヒョウタンを指した言葉に由来します。

各州の風土に適応した地方品種も豊かで、稜の深い **ロマネスコ**（ラツィオ州）、繊細な **フィオレンティーノ**（トスカーナ州）、*C. moschata* に属する細長い **トロンベッタ・ディ・アルベンガ**（リグーリア州）などが知られます。これらの多くは伝統的農産物（PAT）として保護され、スローフード運動とともに再評価されています。

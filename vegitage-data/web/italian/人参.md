# 人参

*Daucus carota L.* — 紫と黄の記憶を残す多色根菜

人参は、セリ科（Apiaceae）の二年生草本で、肥大した直根を食用とします。中央アジアで10〜11世紀頃に栽培化された初期の品種は紫や黄色で、シルクロードを経て中世盛期のイタリアへ伝わり、当初は薬草として利用されました。今日おなじみのオレンジ色は、16〜17世紀のオランダで **オラニエ家** への敬意から選抜された比較的新しい色です。

ルネサンス期のイタリアでは、**マッティオーリ** や **アルドロヴァンディ** が「汚れた白」「黄」「紫」の多様な人参を記録し、メディチ家の宮廷画家 **ビンビ** らの静物画も標準化以前の多彩さを伝えています。オレンジ品種の席巻後も、南部を中心に古い色の遺伝子が自家採種で守られてきました。

地域固有品種として、プーリア州の **ポリニャーノ**（汽水で育つ多色種、スローフード・プレシディオ）、サレント半島 **ティジャーノ** の「聖ヒュパティオスのペスタナカ」（1月19日の祭礼と結ぶ紫黄の在来種）が知られます。近代栽培の成功例ではシチリアの **イスピカ**（逆シーズンのIGP新参）、アブルッツォの干拓地 **フチーノ高原**（IGP）が代表格で、イタリアは人参の遺伝的多様性の重要な保存庫となっています。

詳しくは各ガイドへ ── **歴史**（多色の起源・ルネサンスの記録・オレンジ化・地域品種と祭礼）／**栽培**／**料理**。

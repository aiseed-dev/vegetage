# ホウレンソウ

*Spinacia oleracea L.* — アラブの農業革命が伝えた葉物野菜

ホウレンソウは、ヒユ科（旧アカザ科）に属する一年生ないし二年生の葉菜です。野生種は中央アジアから南西アジアに自生し、栽培は2,000年以上前の古代ペルシアに遡ります。イタリアへの導入で決定的だったのは9世紀の **シチリア** で、アグラブ朝（サラセン人）による征服とともにイスラム圏の灌漑技術や植物知識が持ち込まれ、ホウレンソウもその「農業革命」の一環として伝わりました。

シチリアから北上して普及し、14世紀初頭にはミラノの記録にも現れます。肉厚で冬でも収穫でき、四旬節の代替食材として修道院や貴族に重宝されました。フランス料理の「フィレンツェ風（アラ・フィオレンティーナ）」がホウレンソウと結びつくのは、**カトリーヌ・ド・メディシス** の伝説によるとされますが、食物史家はこれを慎重に「神話」として扱っています。

長い栽培のなかで各地に在来種が育まれ、耐寒性の **ギガンテ・ディンヴェルノ**、濃緑で繊細な **メルロ・ネロ**、ピエモンテの **リッチョ・ダスティー** などが伝わります。トスカーナのヴァル・ディ・コルニア産はPATに認定され、スローフードの「味の箱舟」も在来種の保存に取り組んでいます。

詳しくは各ガイドへ ── **歴史**（ペルシア起源・シチリア伝来・メディチ伝説・在来品種）／**栽培**／**料理**。

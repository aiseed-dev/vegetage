# オレンジ

*Citrus sinensis* — 地中海の「黄金の果実」

オレンジは、ミカン科（Rutaceae）の常緑果樹で、その果実が利用されます。イタリアへの導入は二つの波に分けられます。9〜11世紀、シチリアを支配したアラブ人が灌漑技術とともにビターオレンジ（*Citrus aurantium*）を鑑賞・薬用・調香用として持ち込み、砂糖漬け菓子の基盤を築きました。生食に適したスイートオレンジ（*Citrus sinensis*）は15〜16世紀にポルトガル人航海者を通じて広まり、各地の方言で「ポルトガル」と呼ばれる呼称にその経路が刻まれています。

生産の中心は **シチリア** で、**エトナ火山**の寒暖差がアントシアニンの生成を促し、**タロッコ**・**モーロ**・**サングイネッロ** といったブラッドオレンジ（**Arancia Rossa di Sicilia IGP**）を生みます。南西部リベラのブロンドオレンジは **Arancia di Ribera DOP** に、プーリアの **Arancia del Gargano IGP** は石壁で囲われた古い果樹園「ジャルディーニ」で守られてきました。カンパニアの **ソレント** や **パガーニ** も歴史的産地です。

北部でもメディチ家が越冬施設で柑橘を集めた **トスカーナ** の奇種「ビッツァリア」や、栽培北限の **ガルダ湖** のリモナイエが知られます。現在は病害や気候変動に直面しつつ、DOP・IGP制度とスローフード運動が伝統品種に新たな価値を与えています。

詳しくは各ガイドへ ── **歴史**（アラブとポルトガルの伝播・地域品種）／**栽培**／**料理**。

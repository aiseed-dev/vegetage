# パースニップ

*Pastinaca sativa* — 古代ローマの主要根菜、忘れられた味

パースニップは、セリ科（Apiaceae）に属する二年生植物で、白く肥大した根を食用とします。今日では「北欧の野菜」と見なされがちですが、その文化的起源は深く地中海世界に根ざしています。古代ローマでは大プリニウスが『博物誌』に記録するほど重んじられ、皇帝ティベリウスはライン川流域の **ゲルデュバ** 産を毎年取り寄せたと伝えられます。霜に当たると糖化して甘味を増す性質が、当時貴重な甘味の源として珍重されました。

中世には「貧者のパン」として農民の冬の炭水化物源となり、四旬節など肉食を断つ日の料理を支えました。しかし新大陸から伝わったジャガイモに、収量と生育効率の点で敗れ、19世紀末までに都市部の食卓からほぼ姿を消します。

一方で、寒冷な山間部や祝祭の中で在来種は生き残りました。アブルッツォ州の **カピティニャーノのパースニップ** はスローフードのプレシディオに認定され、クリスマス・イブの儀礼食として今に伝えられています。近年は独特の芳香を持つ食材として、ガストロノミーや生物多様性保護の文脈で再評価が進んでいます。

詳しくは各ガイドへ ── **歴史**（古代ローマ・中世の糧・衰退・在来種の復興）／**栽培**／**料理**。

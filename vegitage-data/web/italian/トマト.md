# トマト

*Solanum lycopersicum* — 黄金の果実「ポモ・ドーロ」

トマトは、ナス科（Solanaceae）に属し果実を食用とする果菜です。16世紀前半に新大陸からもたらされ、シエナの医師 **マッティオリ** が1544年に記録した個体が黄金色であったことから「ポモ・ドーロ（黄金のリンゴ）」と名づけられました。当初は毒草マンドラゴラに近縁と見なされ、約2世紀のあいだ観賞用にとどまりましたが、17世紀末の **ナポリ** で食用へ転換し、ラティーニやコッラードの料理書を経てパスタと結びつき、1837年のカヴァルカンティの著書で国民食として成文化されました。

19世紀にはピエモンテ出身の **チリオ** が缶詰の産業化を、エミリアの **パルマ** で農学者ロニョーニが加工用栽培を確立し、トマトを一年中使える基礎食材に変えました。各地のテロワールが多様な品種を育み、カンパニアの **サン・マルツァーノ DOP** や吊るして保存する **ピエンノロ DOP**、シチリアの **パキーノ IGP**、乾燥地農法の **シッカーニョ**、種子主権の象徴 **コストルート・フィオレンティーノ** などが知られます。

DOP/IGP制度は生産規定に基づき「本物」を保護し、産地を偽る「イタリアン・サウンディング」製品との闘いも続いています。トマトは今日、地中海食と国民的アイデンティティの要石です。

詳しくは各ガイドへ ── **歴史**（黄金のリンゴの命名・ナポリでの食用化・産業化・DOP品種）／**栽培**／**料理**。

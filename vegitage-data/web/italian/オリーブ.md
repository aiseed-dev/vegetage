# オリーブ

*Olea europaea* — 地中海文明が育てた「液体の黄金」の木

オリーブは、モクセイ科（Oleaceae）に属する常緑の果樹で、その果実と搾油されるオリーブオイルが利用されます。祖先種は氷河期以前から地中海地域に自生し、果実の大きい栽培種への改良は約6000年前にレバント地方で始まったとされます。イタリア半島へは紀元前8〜7世紀頃、ギリシャ人入植者やフェニキアの商人によって南部の**マグナ・グラエキア**へ、また**エトルリア**人を介して**トスカーナ**や**ラツィオ**の丘陵地へと伝わりました。

ローマ帝国はオリーブオイルを食用・照明・衛生・儀礼にわたる戦略物資とし、栽培を地中海全域の一大産業へ育てました。西ローマ崩壊後は修道院が技術を保存し、**リグーリア**の**タジャスカ**種のように優れた品種選抜と段々畑が地域景観の基礎となりました。中部イタリアでは折半小作制度メッザドリアが混植農業と絵画的な景観を形づくりました。

イタリアは500種を超える品種を持つ多様性の国で、生産量最大の**プーリア**の**コラティーナ**、**トスカーナ**の**フラントイオ**、**シチリア**の**ノチェッラーラ・デル・ベリーチェ**などが知られ、多くがDOP・IGPに認定されています。現在はピアス病菌（*Xylella fastidiosa*）の被害や気候変動という課題に直面しつつ、抵抗性品種の導入と持続可能性を軸に転換期を迎えています。

詳しくは各ガイドへ ── **歴史**（古代の伝播・ローマの産業化・品種と病害）／**栽培**／**料理**。

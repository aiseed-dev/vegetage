# チコリー（プンタレッレ）

*Cichorium intybus L. var. foliosum* — ローマの冬を告げる苦味

プンタレッレは、キク科（Asteraceae）キクニガナ属の **チコリア・カタローニャ** のうち、肥大した花茎（tallo）を食用とする「アスパラガス・チコリア」系のサブグループです。チコリアの利用は古代エジプトの医学書やプリニウス『博物誌』にまで遡り、薬草としての歴史を持ちます。「カタローニャ」の名はスペインのカタルーニャ地方に由来するとされますが、イタリア中南部で葉より花茎を肥大させる方向へ選抜が進み、独自の青果物として成立しました。

とりわけ **ローマ**（ラツィオ州）では冬の風物詩として親しまれ、方言で「チコリオーネ」と呼ばれます。花茎を細く裂いて氷水にさらしカールさせる下処理を経て、アンチョビとニンニクのソースで和える「プンタレッレ・アッラ・ロマーナ」となり、料理研究家アダ・ボーニが1930年の著書で成文化しました。もう一つの中心地 **プーリア州** では、サレント地方の **チコリア・ディ・ガラティーナ** やバーリ北方の **モルフェッテーゼ** が伝統的農産食品（PAT）に登録されています。

多くの農家が自家採種でエコタイプを維持してきた歴史を持ち、PAT認定やモルフェッタでのIGP取得の動きを通じて、その価値は文化遺産として高まっています。

# セロリ

*Apium graveolens L.* — 神話に始まる香味野菜、テロワールの多様性

セロリは、地中海沿岸を原産とするセリ科（Apiaceae）の二年草です。イタリア語では **セダノ（Sedano）** と呼ばれ、主に葉柄（茎）を食用とする *dulce* 種を中心に多彩な在来品種が育まれてきました。古代ギリシャ・ローマでは、勝者の冠であると同時に死者に手向ける植物でもある両義的な象徴であり、また利尿・消化を助ける薬草でもありました。シチリアの古都 **セリヌンテ** の名も、野生セロリ（selinon）に由来します。

薬草から野菜への転換は中世後期からルネサンス期に進み、16〜17世紀にはスカッピの料理書やカステルヴェトロのサラダ論を通じて食材としての地位を確立しました。

イタリアの最大の特色は、各地の風土に適応した多様なエコタイプの存在です。IGP認定の **スペルロンガの白セロリ**、紙巻きで白化させる **トレヴィの黒セロリ**、サヴォイア家ゆかりの **オルバッサーノの赤セロリ**、高地栽培の **ルッビオのセロリ** などが、スローフードやPATによって保護されています。料理では、玉ねぎ・人参と組む「ソッフリット」の土台を担う一方、プラート風セロリのように主役ともなります。

詳しくは各ガイドへ ── **歴史**（古代の象徴・薬草からの転換・地域品種・軟白技術）／**栽培**／**料理**。

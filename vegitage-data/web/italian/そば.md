# そば

*Fagopyrum esculentum* — アルプス山岳地域の「黒い穀物」

そばは、タデ科（Polygonaceae）に属する擬穀類です。イネ科の穀物ではありませんが、三角形の実を製粉して主食としてきたため、慣習的に「穀類」として扱われます。イタリア語では **Grano Saraceno（サラセン人の穀物）** と呼ばれ、その名が中世に外来作物として伝わった経路を今に伝えています。

寒冷で痩せた土地でも 60〜90 日の短い期間で実る性質から、トウモロコシが普及するまでの高標高地では貴重な炭水化物源でした。とりわけ北イタリアのアルプス地域 ── ロンバルディア州の **ヴァルテッリーナ** とトレンティーノ＝アルト・アディジェ州 ── では、単なる食料を超えて地域のアイデンティティを支える食文化の柱となっています。

一度は衰退したそば栽培は、近年、地域の伝統料理（ピッツォッケリやポレンタ・タラーニャ）とともに再評価されつつあります。

詳しくは各ガイドへ ── **歴史**（語源・アルプスへの伝播・地域文化・衰退と復興）／**栽培**／**料理**。

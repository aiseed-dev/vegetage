# セルリアック

*Apium graveolens var. rapaceum* — 球状に肥大する「セーダノ・ラーパ」

セルリアックは、セリ科（Apiaceae）に属する二年草で、球状に肥大した下胚軸を食用とする根菜です。イタリア語では **セーダノ・ラーパ（sedano rapa）** と呼ばれます。外皮は褐色で節くれだっていますが、内部は純白で、ナッツのような風味とセロリ特有の芳香を併せ持ちます。

祖先は地中海盆地の湿地帯に自生する野生セロリで、古代には主に薬用植物として扱われました。根が肥大した形態が食用として明確に記録されるのはルネサンス期のイタリアで、1554年のマッティオーリ、1585年のドゥランテらの本草書に現れます。ここで洗練された品種は16〜17世紀にフランスへ伝わり、欧州全域へ広がりました。

17世紀以降、栽培は北イタリアで専門化し、とりわけ **ヴェネト州ヴェローナ** 近郊で **ヴェローナ種（Sedano di Verona）** の基礎が築かれました。冬の貯蔵野菜として重んじられ、戦時下には安価な栄養源としても人々を支えました。現在はヴェネト州の **ロンコ・アッラーディジェのセルリアック** が伝統的農産物（PAT）に認定され、スローフードの潮流のなかで再評価が進んでいます。

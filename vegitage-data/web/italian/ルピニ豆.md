# ルピニ豆

*Lupinus albus* — 苦味を抜いて食べ継いだ「貧者の肉」

ルピニ豆は、マメ科（Fabaceae）の一年生植物である白ルピナス（*Lupinus albus*）の種子です。地中海沿岸から西アジアを原産とし、痩せた酸性土壌でも育ち、根粒菌による窒素固定で土地を肥やすことから、古代ローマの博物学者プリニウスも緑肥・飼料・食料・薬用の多機能作物として記録しています。

在来の品種はキノリチジン系アルカロイドを高濃度に含む有毒な「苦味種」で、食用にするには煮沸と長期の水晒し（脱苦味処理）が欠かせませんでした。この加工技術が受け継がれたことで、イタリアは甘味種が普及した現代でも、あえて苦味種を塩水漬けにして食べる稀な食文化を保っています。ジョヴァンニ・ヴェルガの小説『**悪意ある家**』では「貧者の交易品」として、また「決して人を満腹にさせない豆」の伝承として、文学や民話にも刻まれてきました。

地域固有種として、カンパニア州の **ヴァイラーノの巨大ルピナス**（スローフード・プレシディオ）、南チロルの **アンテリーヴォ** でコーヒー代用に焙煎される品種、プーリア州 **タヴォリエレ** の白ルピナスなどが伝統的農産物（PAT）に認定されています。近年は高タンパク・グルテンフリーの食材、また大豆に代わる域内タンパク資源としてEUで再評価されています。

詳しくは各ガイドへ ── **歴史**（古代ローマの多機能作物・脱苦味処理・文学と伝承・地域品種）／**栽培**／**料理**。

# ブロッコリー

*Brassica oleracea* var. *italica* — 地中海の遺産としてのブラシカ属

ブロッコリーは、アブラナ科の野生種 *Brassica oleracea* を原種とする変種で、未熟な花蕾を食用とします。地中海沿岸に自生する野生キャベツから、ケールやカリフラワーとともに分化しました。イタリア半島は「イタリカ種」の二次的な栽培化の中心地とされます。語源はラテン語の「brocchus（突き出た）」や「brachium（腕）」に連なり、主茎から多数の側枝を伸ばすスプラウティング型の形態を映しています。古代ローマでは花茎を「**キマ（Cyma）**」と呼び、大プリニウスが皇帝ティベリウスの息子の逸話とともに記録しています。

中世は修道院の菜園で命脈を保ち、ルネサンス期には **カテリーナ・デ・メディチ** がフランスへ伝えたとされ、「イタリアのアスパラガス」と呼ばれました。

各地に多様な在来種が残り、ヴェネトの **フィオラロ・ディ・クレアッツォ**、ガルダ湖の **トルボレのブロッコリー**、ラツィオのフラクタル状の **ロマネスコ**、カンパニアの **パテルノポリのアプリラティコ** などが、PATやスローフードのプレシディオとして保護されています。世界標準のブロッコリーはカラブリア州の品種が移民を通じ広まったものです。

詳しくは各ガイドへ ── **歴史**（語源・古代ローマ・修道院・地域の在来種）／**栽培**／**料理**。

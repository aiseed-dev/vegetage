# ピーマン

*Capsicum annuum* — 新世界が贈った彩りの宝石「ペペローネ」

ペペローネは、ナス科（Solanaceae）トウガラシ属の *Capsicum annuum* の甘味変種で、果実を食用とします。中南米を原産とし、1492年のコロンブス交換を経て欧州へもたらされました。イタリア語の「Peperone」はラテン語の「Piper（胡椒）」に由来し、当初は高価な黒胡椒の代替、あるいは観賞用・薬用として扱われました。本草学者 **マッティオーリ** は「美しき毒」として記述し、食用としての定着には時間を要しました。

真に食文化へ根付いたのは17〜18世紀で、痩せた土地でも育つ強健さと保存性から、南イタリアでは乾燥・粉末化して香辛料の代用とされました。ナポリのヴィンチェンツォ・コッラードらを経て、美食の領域へと昇華していきます。

地域固有品種が豊かで、ピエモンテの **カルマニョーラ**、バジリカータの **セニーゼのペペローネ（IGP）**、ラツィオの **ポンテコルヴォ（DOP）**、カンパニアの **パパッチェッラ・ナポレターナ** などが知られます。スペインやオランダの大量生産に対し、イタリアはDOP/IGPや在来種の多様性を武器に独自の地位を築いています。

詳しくは各ガイドへ ── **歴史**（新世界からの到来・南北の在来品種・DOP/IGP）／**栽培**／**料理**。

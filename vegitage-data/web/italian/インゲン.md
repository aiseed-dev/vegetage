# インゲン

*Phaseolus vulgaris* — 「貧者の肉」から美食の象徴へ

インゲンは、マメ科（Fabaceae）に属し、成熟した種子（ファジョーリ）や未熟な鞘（ファジョーリニ）を食べます。新大陸原産で、16世紀のコロンブス交換によりイタリアへ渡りました。旧世界にはすでにササゲ（*Vigna*）の「豆」概念があったため受容は速く、生産性と食味に優れた *Phaseolus* は「貧者の肉」として定着しました。

導入は教皇 **クレメンス7世**（メディチ家）と人文学者 **ピエロ・ヴァレリアーノ** によるトップダウン型で進み、ヴァレリアーノは **ベッルーノ** 地方で栽培実験を行いました。遺伝的にはアンデス系の系統が主流です。各地の農民が数世紀にわたり選抜を重ね、数百の在来種（ランドレース）が生まれました。

ヴェネトの **ラモン豆**（IGP）、トスカーナの **ソラーナ豆**（IGP、ロッシーニやプッチーニが愛好）や **ゾルフィーノ豆**、バジリカータの **サルコーニ豆**（IGP）や **ロトンダの白いんげん豆**（DOP、ガリバルディの逸話）など、IGP/DOP品種が豊富です。カラッチの絵画やトスカーナの「フィアスコ」調理法にも豆の文化が刻まれています。

詳しくは各ガイドへ ── **歴史**（コロンブス交換・教皇庁の導入・地域品種）／**栽培**／**料理**。

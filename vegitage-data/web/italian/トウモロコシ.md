# トウモロコシ

*Zea mays* — 北イタリア農業を変えた新大陸の穀物

トウモロコシは、イネ科（Poaceae）に属し実（穀粒）を食用とする穀物です。1492年の新大陸到達以降にヨーロッパへ伝わり、16世紀初頭にヴェネツィア共和国の交易路などを通じて北イタリアへ流入しました。イタリア語の「Granturco（トルコの穀物）」は、遠方の外来物を指す当時の慣習に由来する呼称です。高い収量と適応力から、**ポー平原** を中心に自家消費用の主食作物として急速に広まり、17世紀にはロンバルディア州 **ガンディーノ** で1632年の栽培記録が残されています。

19世紀の北イタリアはトウモロコシ粉の粥「ポレンタ」を主食とする文化圏を形成しましたが、極端な偏食はナイアシン欠乏症「ペラグラ」の蔓延を招き、その原因が解明されたのは20世紀に入ってからでした。各地では農民の選抜により、硬質でガラス質の在来種（ランドレース）が育まれ、ヴェネト州の **マラーノ** や白い **ビアンコペルラ**、ガンディーノの有棘種 **スピナート**、トレンティーノの **ノストラーノ・ディ・ストーロ**、ピエモンテの **オットフィーレ** などが知られます。

近代化で在来種の多くが均質なハイブリッド種に置き換わりましたが、DOP/IGPやPAT、スローフードの「Slow Mays」、CREAの種子銀行などにより、生きた文化財として保全と再評価が進んでいます。

詳しくは各ガイドへ ── **歴史**（導入と定着・ポレンタ文明とペラグラ・地域在来種・現代の保全）／**栽培**／**料理**。

# エンダイブ

*Cichorium endivia* — キク科の苦味野菜、リッチァとスカローラ

エンダイブは、キク科（Asteraceae）の *Cichorium* 属に属する葉菜で、独特の苦味を持ちます。葉が縮れた **インディヴィア・リッチァ**（生食向き）と、葉が広く肉厚な **インディヴィア・スカローラ**（加熱にも耐える）の2変種に大別されます。語源は古代ギリシャ語を経て、エジプト語で1月を意味する語に遡るとされ、冬に育つ作物であることを物語ります。

古代ローマではプリニウスらが記録し、消化を助ける食材とされました。中世にはフランク王国の宮廷医アンティムスがグアンチャーレと合わせる調理を記し、**サレルノ医学校** では眼病薬にも用いられました。ルネサンス期にはマッティオリが分類し、光を遮って苦味を抑える **軟化（Imbianchimento）** 技術も確立していました。

生産の重心は南部の **プーリア**、**アブルッツォ**、**カンパニア** にあり、北部では **ベルガモの丘のスカローラ** など高付加価値の伝統品種（PAT）が守られています。ナポリのクリスマスの **ピッツァ・ディ・スカローラ**、ローマのユダヤ料理 **アリチョッティ・コン・リンディヴィア** など、苦味を旨味と調和させる食文化を象徴する野菜です。

# イチジク

*Ficus carica* — 文明の記憶を宿す地中海の甘い恵み

イチジクは、クワ科（Moraceae）に属する果樹で、その果実を食用とします。学名は小アジアの **カリア** 地方に由来し、パレスチナやエジプトでは小麦よりも早く栽培化された可能性のある古い作物です。イタリア半島へはフェニキア人やギリシャ人の植民、特に南部の **マグナ・グラエキア** を通じて導入されました。

古代ローマでは、大カトーが元老院で新鮮なイチジクを示してカルタゴの近さを訴えた逸話が有名です。中世には乾燥イチジクが高カロリーで保存の利く「貧者のパン」となり、飢饉や戦乱を凌ぐ命綱となりました。ルネサンス期の四体液説は「生ハムとイチジク」の組み合わせを生み、メディチ家は栽培を奨励しました。

南北に長いイタリアでは地域ごとに品種と加工文化が発達しました。カンパニアの **チレントの白イチジク**（DOP）、カラブリアの **コゼンツァのイチジク**（DOP、種の小さいドッタート種）、フリウリの **カネヴァの黒イチジク**、トスカーナの **カルミニャーノ** などが知られ、乾燥イチジクにクルミやアーモンドを合わせる保存食も各地に伝わります。現在イタリアはEU域内でスペインに次ぐ第2位の生産国で、数量よりDOP/IGP製品への特化が進んでいます。

詳しくは各ガイドへ ── **歴史**（カトの警告・貧者のパン・地域品種）／**栽培**／**料理**。

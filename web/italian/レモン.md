# レモン

*Citrus limon* — 太陽と潮風が育む地中海の黄金

レモンは、ミカン科（Rutaceae）の常緑高木になる果実で、チェドロ（*Citrus medica*）とビターオレンジの自然交雑種と考えられています。イタリア半島の柑橘の歴史は、紀元前にユダヤ人のディアスポラと共に南部へ伝わったチェドロに始まり、9世紀のアラブ支配下でシチリアに灌漑技術とレモンがもたらされ、パレルモの「コンカ・ドーロ」が柑橘の森となりました。中世には修道士がガルダ湖畔まで栽培を北上させています。

19世紀のシチリアは世界のレモン市場を席巻し、壊血病予防やクエン酸産業で「黄色い金」と呼ばれました。北イタリアの **ガルダ湖** では、石柱の温室建築「リモナイエ」が高緯度栽培を可能にしています。

地域固有品種が豊かで、カンパニア州の **アマルフィ（スフザート）** と **ソレント（フェミネッロ）** の各IGP、**プロチダ島** の厚いアルベドを食べる「パンのレモン」、メッシーナの **インテルドナート**、プーリアの **ガルガーノ**（イタリア最古級・1003年の記録）、カラブリアの **ロッカ・インペリアーレ**、そしてサルデーニャの「怪物」**サ・ポンピア** など、IGP・DOP・スローフードに認定された品種が各地に息づいています。

詳しくは各ガイドへ ── **歴史**（チェドロの到来・アラブ農業革命・シチリア産業史・地域品種）／**栽培**／**料理**。

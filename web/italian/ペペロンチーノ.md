# ペペロンチーノ

*Capsicum* spp. — 南の大地を燃やす小さな悪魔

ペペロンチーノは、ナス科（Solanaceae）トウガラシ属の果実で、イタリアで栽培される大半は *Capsicum annuum* に属します。原産は中央・南アメリカで、コロンブスの交換によって欧州へ伝わり、16世紀中頃にスペイン統治下の南イタリアを経て流入しました。当初は貴族に敬遠されましたが、庭先で容易に育つことから農民層に「貧者のスパイス」として定着しました。

とりわけ南イタリアで文化に根づき、**カラブリア** はその中心地です。2025年には **Peperoncino di Calabria** のIGP登録手続きが始まり、海岸の町ディアマンテではペペロンチーノ祭りが開かれています。**バジリカータ** の **Peperone di Senise IGP**（1996年認証）は辛くない品種で、乾燥させて揚げる「ペペローニ・クルスキ」で知られます。プーリアやアブルッツォ、カンパニアにも伝統品種（PAT）が伝わります。

南イタリア、特にナポリでは、その赤く尖った形が邪視を払う魔除け「コルノ（角）」と同一視されてきました。カラブリアの塗るサラミ **ンドゥイヤ** では、カプサイシンの抗菌作用が保存の要となっています。

外来のスパイスがイタリアの伝統へと変貌した、異文化受容の代表例といえます。

詳しくは各ガイドへ ── **歴史**（新大陸起源・貧者のスパイス・カラブリアとセニーゼ）／**栽培**／**料理**。

# カブとチーマ・ディ・ラーパ

*Brassica rapa L.* — 「根」と「葉」の二つの顔を持つ地中海の万能野菜

カブとチーマ・ディ・ラーパは、いずれもアブラナ科（Brassicaceae）の *Brassica rapa* に属します。イタリアではこの種が南北で大きく二極化しました。北部の寒冷地では肥大した根を利用する根用カブ（subsp. *rapa*）が、南部の温暖な気候では花蕾と葉を利用するチーマ・ディ・ラーパ（subsp. *sylvestris*）が発達し、食文化の二重構造を象徴しています。

古代ローマではプリニウスが「穀物に次いで有用な作物」と評し、中世北イタリアではジャガイモ伝来以前の重要な炭水化物源でした。近世になると、プーリア出身の **ヴィンチェンツォ・コッラード** や **イッポリト・カヴァルカンティ** らが南部の葉野菜を記録し、ナポリのソウルフード「**フリアリエッリ**」の原型を定着させました。

南部では **プーリア** がチーマ・ディ・ラーパの中心地で、収穫日数で呼ぶ **セッサンティーナ**（60日）などを使い分け、**オレッキエッテ** と合わせる料理が名高いです。カンパニアの **フリアリエッリ**、ラツィオの **ブロッコレッティ** も同系です。北部では根を用い、フリウリの発酵食品「**Brovada**」がイタリア唯一のカブのDOPに、ピエモンテの **Rapa di Caprauna** がスローフードのプレシディオに認定されています。多くの在来種はPATとして保護されています。

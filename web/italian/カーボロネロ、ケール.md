# カーボロネロ、ケール

*Brassica oleracea* — 地中海の「貧者の医者」

カーボロネロとカーボロ・リッチョは、アブラナ科アブラナ属（*Brassica oleracea*）のうち結球しない（アケファラ）葉菜のグループに属します。**カーボロネロ**（var. *palmifolia*）は黒に近い濃緑色で表面が縮れた葉を直立させ、**カーボロ・リッチョ**（var. *acephala* / *sabellica*）は縁が激しく縮れます。近年の遺伝学的研究は地中海東部起源説を支持しており、イタリア半島は品種が多様化する二次的中心地となりました。

古代ローマでは、大カトーが著書『農業論』でキャベツを「すべての野菜の中で第一のもの」とし、万能薬として重んじました。大プリニウスは縮れ葉の **Brassica sabellica** を記録しており、これが現在のカーボロ・リッチョにつながります。中世からルネサンス期にかけて、フィレンツェのソデリーニが16世紀に「トスカーナの黒キャベツ」を明確に記述し、**トスカーナ** 固有の品種として確立しました。

**カーボロネロ** は霜に当たると甘みを増す性質があり、トスカーナの煮込み料理 **リボッリータ** に欠かせません。プーリア州の **カーボロ・リッチョ**（Cole Rizze）は貧しい農村を支えた野菜で、現在はいずれもPAT（伝統的農産物）として保護されています。

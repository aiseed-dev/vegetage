# 小麦

*Triticum* spp. — 文明を育んだ黄金の穂

小麦（*Triticum*属）は、イネ科（Poaceae）に属する穀類で、実（穎果）を製粉して主食とします。イタリアで栽培されてきた小麦は、二倍体の一粒小麦、四倍体の二粒小麦（ファッロ）や硬質小麦（デュラム）、六倍体の軟質小麦（パン用）など、複数の倍数性グループにまたがります。「肥沃な三日月地帯」で栽培化された小麦は、シチリア島を「ローマの穀倉」とする古代から、イタリア半島の歴史と社会を形づくってきました。

品種改良の歴史も豊かです。20世紀初頭、農学者 **ナザレーノ・ストランペッリ** が日本の **アカコムギ** を交配親に用い、倒伏に強い早生品種群を作出しました。デュラム小麦の **セナトーレ・カッペッリ** は、現代イタリアンパスタの基礎を築いた品種です。地域には、シチリアの **ティミリア** や **ルッセッロ**、トスカーナの **ヴェルナ** や **ジェンティル・ロッソ** といった在来品種が伝わります。

品質認証も充実しており、二粒小麦の **ファッロ・デッラ・ガルファニャーナ**（IGP、トスカーナ）、**アルタムーラのパン**（DOP、プーリア）、**グラニャーノのパスタ**（IGP、カンパニア）などが伝統的品種や製法を守っています。近年は「古代小麦（Grani Antichi）」が、生物多様性や低投入型農業の観点から再評価されています。

詳しくは各ガイドへ ── **歴史**（栽培化・ストランペッリの品種改良・小麦の戦い・古代小麦の復興）／**栽培**／**料理**。

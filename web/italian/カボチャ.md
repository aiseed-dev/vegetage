# カボチャ

*Cucurbita maxima* — 新大陸から来たウリ科の多様な品種群

カボチャは、ウリ科（Cucurbitaceae）カボチャ属（*Cucurbita*）の果菜で、その果実が食用とされます。1492年のアメリカ大陸到達以前、イタリアの「ズッカ（Zucca）」は旧大陸原産のユウガオ属（*Lagenaria*）を指し、主に容器として用いられました。新大陸から *Cucurbita* 属が伝わると、既存の「ズッカ」の名がそのまま転用され、食用価値の高い新種が旧来種に取って代わりました。ローマの **ヴィッラ・ファルネジーナ** の1515〜18年のフレスコ画には、ヨーロッパ最古とされる *Cucurbita maxima* が描かれています。

イタリアでは気候に応じて3種が分化しました。北部のポー平原では大型で保存性の高い *Cucurbita maxima* が優勢で、ヴェネトの **Marina di Chioggia**、ロンバルディアの **Zucca Mantovana**、パヴィア県の **Berrettina di Lungavilla** などが伝統品種として知られます。中南部・沿岸部では香り高い *Cucurbita moschata* が好まれ、フェラーラの **Violina**、ナポリの **Lunga di Napoli**、リグーリアの **Trombetta d'Albenga** が代表的です。

ルネサンス期の宮廷料理人によって洗練され、フェラーラやマントヴァの詰め物パスタ（**Cappellacci di Zucca Ferraresi IGP** など）へと発展しました。現在はF1品種が普及する一方、多くの伝統品種がPAT（伝統的農産物）として保護されています。

詳しくは各ガイドへ ── **歴史**（旧大陸から新大陸種へ・地域品種・食文化）／**栽培**／**料理**。

# レンズ豆

*Lens culinaris* — 大晦日に食べる「金貨」の豆

レンズ豆は、マメ科（Fabaceae）の一年生植物の種子で、肥沃な三日月地帯で栽培化され地中海へ広まった最古級の作物のひとつです。イタリアでは新石器時代の遺跡から炭化種子が出土し、穀物と組み合わせてアミノ酸を補い合う「貧者の肉」として農村の生存を支えてきました。

古代ローマでは民衆や兵士の食料であると同時に、アピシウスの料理書に洗練されたレシピが残る二面性を持ちました。硬貨に似た形から富の象徴とされ、大晦日にレンズ豆を食べて金運を願う習慣は、コテキーノやザンポーネと共に現代まで続く国民的儀式です。中世にはオナノ産が教皇ピオ9世に愛され「**法王のレンズ豆**」と呼ばれ、移牧（トランスマンツァ）を通じて高原へ種子が運ばれました。

品種は各地の風土に適応し、ウンブリアの **カステッルッチョ・ディ・ノルチャ**（IGP、標高約1450m、浸水不要の小粒）、プーリア／バジリカータの **アルタムラ**（IGP、大粒）が代表格です。シチリアの **ウスティカ島**（国内最小）や **ヴィッラルバ**、ラツィオの **ラシーノ** や **オナノ** はスローフードやPATに認定されています。窒素固定による土壌改良や自然乾燥が、輸入品との差別化としても再評価されています。

詳しくは各ガイドへ ── **歴史**（先史の栽培・ローマの象徴性・法王の豆と移牧・地域品種）／**栽培**／**料理**。

# ストリドーロ

*Silene vulgaris* — ナデシコ科の春の野草、農村文化の味

ストリドーロは、ナデシコ科シレネ属（*Silene vulgaris*）の多年草で、早春の柔らかい新芽や葉を食用とします。風船状に膨らんだ萼が最大の特徴で、路傍や畑の縁など人間の生活圏に自生するため、古くから身近な食材として利用されてきました。イタリア全土で、海岸からアルプスの高山帯まで広く分布します。

方言名は地域ごとに極めて多様です。**エミリア＝ロマーニャ州** の「Stridolo / Strigoli」はラテン語の *stridulus*（軋む音）に由来し、葉を擦ると音が鳴ることにちなみます。**フリウリ** の「Sclopit」は、膨らんだ萼を叩いて破裂させる子供の遊びの音に由来します。18世紀にタルジョーニ・トッツェッティが提唱した「フィトアリムルジア（救荒植物利用）」の代表格として、飢饉の際に人々を支えてきた「貧者の糧」でもありました。

現代では郷土料理へと昇華し、フリウリの復活祭の **リゾット・アッロ・スクロピット**、エミリア＝ロマーニャのガレアータで開かれる **ストリドーロ祭**、ヴェネトの「カルレッティ」を使ったフリッタータなどで親しまれます。エミリア＝ロマーニャ、フリウリ、ヴェネトなど複数の州でPAT（伝統的農産物）に認定されています。

詳しくは各ガイドへ ── **歴史**（語源と遊び・救荒植物・祭りと郷土料理）／**栽培**／**料理**。

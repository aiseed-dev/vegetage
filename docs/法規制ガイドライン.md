# 法規制ガイドライン(農家体験サービスの設計ルール)

日付: 2026-08-20
状態: 方針確定(全農家サイトテンプレートに適用)

農家の体験サービスを許可・登録なしで適法に設計するためのルール集。
サイトテンプレートの構成と文言は、このガイドラインに従う。

## 大原則

**売るのは「場所での体験」だけ。行程・送迎・調理・宿泊設備は商品に含めない。**

| 組み込みたいもの | 触れる法律 | 解決策(一行ルール) |
|---|---|---|
| 行程(起点→終点) | 旅行業法 | 行程を売らない。「場所と時間」だけを売る |
| 送迎 | 道路運送法 | 商品の外に置く(無償・付随・料金差なし) |
| 食事 | 食品衛生法 | 調理をお客様に渡す(食材販売+道具貸し) |
| 宿泊(テント) | 旅館業法 | お客様に張らせる(設営済み・寝具提供をしない) |
| キャンプの場所 | 農地法ほか | 宅地を使う(畑・農地でのテント泊は農地転用に該当) |

## 各論

### 1. 旅行業法 — 行程を売らない

- 企画旅行 = 運送または宿泊を含む「行程」を計画して売ること。
  行程を持たない単体の体験(収穫体験・散策ガイド)は旅行業法の対象外。
- **募集ページに時刻入りの行程表を書かない。**
  - 良い例: 「収穫体験 10:00〜15:00 場所: ○○農園(現地集合)」
  - 悪い例: 「9:30 ○○駅集合 → 10:00 畑到着 → …→ 16:00 駅解散」
- 旅行業登録を取っても、自分の白ナンバー送迎・自分の調理は違法のまま
  (登録は「他人の許可済みサービスを仕入れてパッケージする免許」)。
- 登録済み農家は二本立てが可能: 日常商品=単体体験(登録不要)、
  特別商品=貸切バス等を使う企画ツアー(登録が活きる)。

### 2. 道路運送法 — 送迎は商品の外・無償・付随

- 白ナンバー有償運送は白タク(78条違反)。「ツアー代金に込み」も有償と判定される。
- 平成30年通達の「許可・登録を要しない運送」の枠に乗せる条件:
  1. 送迎対象は体験の利用者のみ
  2. 送迎の有無で料金差をつけない(「送迎なし割引」は禁止)
  3. 送迎費の名目で徴収しない・料金に実質上乗せしない
  4. 常識的な範囲(最寄り駅⇔現地)
- **送迎は行程・商品説明に書かず、アクセス欄にのみ書く。**
  「ご希望の方は○○駅まで無料でお迎えします」の形。
- 過疎地特例(自家用有償旅客運送)の主体は市町村・NPO等のみ。個人事業では使えない。
  地域に既存の制度・デマンド交通があればアクセス欄で案内する(予約・支払いは客が直接)。
- お客様同士の自主的な相乗り(実費割り勘)は適法。ただし事業者があっせんしない。
- 保険: 送迎する農家は任意保険の使用目的・補償額を要確認(実質最大のリスク)。

### 3. 食品衛生法 — 調理をお客様に渡す

- 規制対象は「業として調理・提供する行為」。**無償にしても回避できない**
  (送迎と違い、無料サービス化という逃げ道がない)。
- 適法な形: 食材(自家野菜)の販売 + 調理道具(ダッチオーブン・焚き火台)の
  レンタル + 場所貸し。調理するのはお客様(自炊・BBQ方式)。
- 料金の名目の付け替え:
  - 取れない: 食事代、「昼食付きプラン」
  - 取れる: 食材代・道具レンタル代・薪代・場所利用料
- 試食は「洗う・切る」程度の範囲まで(境界は自治体判断)。
- 野菜以外(肉・米)はお客様の持込みにする(食肉販売業許可等を避ける)。
- ちゃんとした食事を出したい場合: 許可のある仕出し・キッチンカーを
  お客様が直接注文する形にする。

### 4. 旅館業法 — お客様に張らせる

- 判定ポイントは「誰のテントか」ではなく「誰が設営するか・寝具を誰が出すか」。
  - 設営済みテント + 寝具提供 = 簡易宿所営業(許可必要)
  - お客様が自分で設営 + 寝具持参 = 場所貸し + レンタル業(許可不要)
- テントのレンタル自体は旅館業ではない。農家自身が貸してよい。
  ただし設営は「お手伝い」程度まで。
- 寝袋レンタルは寝具提供と見なす自治体があるため、貸すなら保健所に確認。
- 「別人にテントを貸させる」等の名義分離は実態判断で否認されるリスクがあり不採用。
  グランピング型をやりたくなったら正面から簡易宿所許可を取る。

### 5. 土地 — 宅地を使う

- **畑(農地)でのテント泊は農地転用(農地法4条)に該当。無断転用は原状回復命令の対象。**
  収穫体験は農地利用の範囲内でセーフ、テント泊はアウトという非対称に注意。
- キャンプは地目が宅地の場所で行う。森は森林法、常設設備は建築基準法・浄化槽法。
- 焚き火: 火災予防条例(届出・制限)、直火禁止条例の有無を自治体に確認。

## 適法なキャンプ体験の完成形

**宅地 + 持込or レンタルテント(客が自分で設営・寝具持参) + 食材販売・自炊
+ 付随の無償送迎(アクセス欄のみ記載) + 焚き火は条例確認**

= 旅行業法・道路運送法・食品衛生法・旅館業法・農地法をすべて回避したまま、
「自分で収穫した野菜を、自分で焚き火で調理して、テントで泊まる」体験が成立する。

## 二つの適法ルート

### ルートA: 登録なしの最小構成(本ガイドラインの基本形)

単体体験 + 無償送迎(アクセス欄のみ) + 自炊 + 客設営テント。
登録・資格・保証金ゼロ。行程表は書けない。すぐ始められる。

### ルートB: 旅行業ルート(行程表つきツアーを売る)

旅行業登録 + 旅程管理主任者 + 適法な運送主体の手配で、
「駅集合→送迎→体験→駅解散」の行程を商品として販売できる。

- 運送の担い手: 自家用有償旅客運送(僻地特例。79条登録の適法な運送
  サービスなので行程に組み込める。ただし制度の有無・協力は自治体次第)、
  または緑ナンバーの貸切タクシー・バス。
  **登録しても自分の白ナンバーで運べない点は変わらない。**
- 食事: 旅行業登録は食品衛生法に効かない。ツアーに含めるなら許可業者から
  調達。「お客様が自炊する体験」を行程に入れるのは提供ではないので可。
- 維持コスト: 営業保証金・旅行業務取扱管理者・約款・書面交付・報告。

**選択基準**: 役場に僻地特例・地域交通の有無を確認してから決める。
制度があればルートB(登録・研修が活きる)、なければルートA(登録を
取り下げてコストを浮かせる)。両ルートの併用も可(日常商品=A、特別商品=B)。

### ルートC: 他社ツアーへの素材提供(登録不要で販路だけ得る)

旅行会社が農家の体験を組み込んだ企画旅行を作る場合、登録・約款・
旅程管理の義務はすべて旅行会社側。農家は「サービス提供者(素材)」なので
**許認可ゼロのまま旅行会社の集客力に乗れる**。体験OTA(じゃらん遊び・
体験、アソビュー等)への掲載も同様(手数料2〜3割)。

チャネル戦略: 新規客はOTA・旅行会社経由(手数料=広告費)、リピーターは
自分のサイト(Vegetage テンプレート)の直販へ誘導(手数料ゼロ)。
Vegetage の位置づけは「手数料ゼロの直販チャネル」であり、OTAと排他ではなく併用する。

補足: 「自分でツアーを作って代理店に受託販売してもらう」ことも制度上は
可能だが、作る側にも旅行業登録が必要(ルートBの負担+受託手数料の二重コスト)。
単一農家では割に合わない。

**登録の置き場所の原理: 束ねる者が登録する。** 複数農家を束ねた周遊ツアー等を
やる場合、登録は農家個々ではなく Vegetage 側(またはプラットフォームが提携する
旅行業者)が一つ持てばよい。農家は全員ルートA+Cのまま許認可ゼロを維持し、
ツアー商品の編集価値はプラットフォームが担う。

## 事前確認リスト(農家ごと)

- [ ] キャンプ予定地の地目(宅地か)— 法務局 or 固定資産税通知
      農地の場合は農業委員会に農地区分を確認。第2種・第3種なら転用許可を
      申請(許可前の使用開始は無断転用)。農用地区域(青地)・第1種なら転用は
      困難なので、隣接する宅地・山林・原野など非農地をキャンプ地に選ぶ
- [ ] 山林を切り開く場合: ①保安林でないか(役場・都道府県林務。保安林なら
      場所変更)、②伐採届(市町村へ30〜90日前、届出制)、③1ha以下なら
      林地開発許可は不要。建物を建てなければ建築基準法も不要
- [ ] 土砂災害警戒区域(イエロー/レッドゾーン)のハザードマップ確認 —
      テント泊させる場所の安全判断として必須
- [ ] 焚き火・火気使用の条例/届出 — 消防・自治体
- [ ] 試食の許容範囲 — 保健所
- [ ] テント・寝袋レンタルの扱い — 保健所
- [ ] 送迎車の任意保険(使用目的・対人対物・搭乗者)— 保険会社
- [ ] 無償送迎の形の確認(念のため)— 運輸支局
- [ ] 地域の有償運送・デマンド交通の有無 — 役場

## サイトテンプレートへの反映

- 体験ページ: 「場所と時間」形式で記載。行程表 UI を作らない
- アクセスページを標準装備: 道順・駐車場・タクシー連絡先・(あれば)無償送迎の案内
- 料金表示: 体験料 / 食材代 / レンタル代 / 薪代 を分けて表示できる構造にする
- キャンプページ: 「テントはご自身で設営」「寝具持参」を明記する定型文を用意
